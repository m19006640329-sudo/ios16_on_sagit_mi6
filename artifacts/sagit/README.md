# sagit (Xiaomi Mi 6) build artifacts

Source-derived files only — no Apple IP, Qualcomm firmware, stock DTB or
device dumps.

| file | what |
| --- | --- |
| `sagit.adt` | Apple Device Tree for MSM8998: 8 CPUs, 1080x1920 splash at 0x9d600000, UFS 0x1da4000, GICR 0x17b00000, 6 GB high RAM. Generated by `tools/mkadt.py --sagit --ram 6`. No iPhone X `/product` node (needs your own IPSW). |
| `sagit-dtb.bin` | Qualcomm DTB tail (3 DTBs: v2.0, v2, v2.1) compiled from MiCode `sagit-o-oss`, board-id 30/0. Append to the boot image kernel section. |
| `shim-sagit-boot.img` | **Probe only** Android boot image (header v1, 4096, kernel 0x8000, ramdisk 0x1000000, dtb 0x1e00000): the sagit shim + DTB tail + empty ramdisk. It boots without XNU, prints board/RAM/UFS and resets after ~3 min. Read-only; does not write partitions. |

`shim-sagit-xnu.img` (the complete image with an XNU payload) is **not** here
because XNU must be compiled on macOS/CI first; see `docs/COOLAPK-SAGIT-INSTALL.md`.

Verify with `sha256sum -c SHA256SUMS`.
